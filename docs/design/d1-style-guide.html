スタイルガイド追補 — 課金・経済圏

Direction A「Console RPG」の実トークンを基底に、課金圏を拡張する。最重要原則: 名声(緑) と 課金(琥珀) を色と形で分離する（発注書 §1.1 / UX §5）。

01 — 系統分離の視覚言語
名声 / 強さ（無償・活動由来）PRESTIGE
色 = --accent 緑/CRT。形 = メタル/シールド。
バッジのティア・リーダーボード・Lv・XP・ストリーク。
この系統に 💎 ルーンアイコン・購入CTAを一切置かない。
通貨は 🪙 コイン のみ（活動でしか増えない）。
課金コスメ / 時短（有償）COSMETIC
色 = --rune 琥珀/金。形 = エフェクト装飾＋COSMETICラベル。
工房グレード・限定バナー・ショーケース枠。
通貨は 💎 ルーン。パスは ✦ 青（時短枠）。
買えるのは「見た目」と「時短」だけ。強さ誤認を作らない。
DO — ティア数値を主(左/上)、コスメ演出を従。ティアが低いのにコスメだけ豪華で「強そう」に見えない配置。
DON'T — 「強くなる/有利/勝てる/効率アップ/差をつけろ」を課金文脈で使わない。代替: 飾る・彩る・時短・限定・コレクション。

03 — 課金コスメのグレード進行（G1→G5）

工房 Lv1→20 を5段階の視覚グレードに写像。アセット制作パイプライン (content-plan §3) の入力。4レイヤー（パレット/フレーム/エフェクト/ショーケース）が段階的に豪華になる。能力は不変・見た目のみ。

04 — 共通コンポーネント仕様
WalletBadge
🪙 1,240💎 340

ヘッダ常設。GET /api/shop/items の coin/rune 残高を SWR 共有。消費成功時 mutate('wallet')。ルーンは琥珀・コインは真鍮で並置分離。

PendingGrantBanner反映待ち

bb.pendingOrder がある間ヘッダ下に常設。15秒間隔で残高再取得、増分検知でトースト。30分で自動失効。「付与済み」と断言しない。

AgeVerificationModal

18歳以上 / 16–17歳 / 16歳未満 の自己申告 → PUT /api/billing/age-verification。直後に「あなたの30日上限 ¥{n}」を明示。サーバが正・localStorageは補助。

DisclosureModal / LegalFooter

確率開示は disclosure API の値をそのままテーブル描画（ハードコード禁止）。LegalFooter は特商法/前払式/規約を課金5画面に常設。「隠さないが叫ばない」。

05 — 数値の桁（正典・ダミー可）

価格 ¥240〜¥12,000 ／ スターター ¥480(170ルーン・初回限定) ／ パス ¥780/月(150ルーン付与) ／ 限定召喚 30ルーン・10連300 ／ 天井 60(パス50)・通常80(パス70) ／ 工房 Lv1=64…Lv20=1,960(累計≒17,240)。価格・確率・天井は本番では必ず API 由来、モックは桁だけ合わせる。
