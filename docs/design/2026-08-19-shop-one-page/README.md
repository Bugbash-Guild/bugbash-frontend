# ショップ1枚化のデザイン記録（2026-08-19）

「ショップのUXわるいんだよな もっとシンプルにならない？」を受けた再設計。
オーナー承認済みのモックと、その前提になった現状分析を残す。
実装は PR #172（`/shop` への統合・タブ廃止）。

| ファイル | 内容 |
|---|---|
| `Main.dc.html` | 承認されたモック: ショップは1枚（チャージ → ルーンの使い道 → コイン → パス） |
| `Current.dc.html` | 変更前の構造と問題点（4タブ・空タブ・死にSKU・2軸ピッカー・説明過多） |
| `canvas.json` | 変更の要点5つ（アートボード配置の注記） |

いずれも素の HTML なのでブラウザで直接開ける。

## 変更の要点（canvas.json より）

1. タブ4枚 → 1ページに統合（チャージ→使い道→コイン→パスの順）
2. 空の「見た目」タブは在庫が入るまで非表示
3. コイン死にSKUは畳んで、正直に「召喚が最効率」を主役に
4. 属性魂パックは1カードに圧縮（属性チップ＋サイズ3択）
5. 説明文を削る — 値段と円換算がそのまま説明になる

## 実装時の規律

モック中の数値（¥3/ルーン・天井60回・¥780/月 等）は例示であり、
実装は全て API の実値から描画する。取れない数値は行ごと出さない
（`bugbash-backend/docs/superpowers/specs/2026-08-09-design-rules.md` 準拠）。
