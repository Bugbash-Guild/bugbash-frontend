スキンライン様式見本

供給パイロットの試作選別用。1ライン＝パレット＋フレーム＋FX＋命名文法＋フレーバーの5点セット。同一モンスター（ドラゴン）で比較できるようにしてあります。

§3 スキンティア・トークン — 第3系統（金属質ニュートラル）style-guide にも追記済み
STD スタンダード · 320ルーン — マット鋼。静的リカラー＋フレーム。#9DA9B5 badge のみ・演出なし
DX デラックス · 880ルーン — 磨き鋼。待機モーション付与。#C7D3DE カードで薄いスペキュラ可
LG レジェンダリー · 1,800ルーン — 鏡面＋玉虫リング（conic虹の淡い縁取り・不透明度50%上限）。登場演出付き。#E2E9F1 虹縁はLG専用・多用禁止

衝突回避ルール: 名声＝緑CRT系／課金通貨＝琥珀／レアリティ＝N灰・R青・SR紫・SSR金。ティアは彩度を持たない金属ニュートラルのみを使い、これらのどれとも同系色にならない。ティアバッジは常に価格またはCOSMETICラベルと併記。

選別の観点（経営者往復用）
1. 視認性 — 小サムネ（Monster Boxカード内）でもライン判別できるか
2. 名声分離 — 緑CRT・琥珀・レアリティ4色と混同しないか（Kernel Panicは緑を使うが走査線テクスチャで区別 — 判断要）
3. Console RPG整合 — ターミナル世界観の内側の言葉で命名できているか
4. 拡張性 — 同文法で20体すべてに展開可能か・季節/イベント亜種を作れるか
本ページは設計ドキュメント（販売画面ではありません）。数値の正: STD 320 / DX 880 / LG 1,800ルーン。
